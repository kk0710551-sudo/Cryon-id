Cryon ID

Decentralized Identity Protocol

Create verifiable, on-chain identities secured by cryptography and stored immutably on the Solana blockchain.

Features

🔐 Wallet Integration

Seamless Phantom wallet connection with multi-wallet support for secure authentication.

📌 IPFS Pinning

Server-side integration with Pinata for secure, decentralized data storage.

⛓️ On-Chain Identity

Anchor program integration for immutable identity records on Solana.

🎨 Minimalist Design

Professional, corporate-Web3 aesthetic with custom color palette.

📱 Responsive Layout

Fully responsive design optimized for desktop, tablet, and mobile.

🔒 Security First

All sensitive operations handled server-side with environment variables.
